CARTOON RALLY 3D — 브라우저 테스트 v2 (효과음 / 조향·그립 / 그래픽 개선)

[실행]
1. ZIP을 폴더에 '모두 압축 풀기' 하세요. ZIP 안에서 바로 실행하지 마세요.
2. index.html을 Chrome 또는 Microsoft Edge로 여세요.
   우클릭 > 연결 프로그램 > Chrome / Microsoft Edge를 선택해도 됩니다.
   START_GAME.bat은 기본 브라우저로 index.html을 여는 편의 파일입니다.
3. START RALLY를 누르고 3초 카운트다운이 끝나면 J로 출발하세요.
4. 첫 번째 게이트를 통과해야 타이머가 시작됩니다.

설치나 인터넷 연결이 필요하지 않습니다. Three.js도 ZIP에 포함되어 있습니다.
WebGL을 지원하는 최신 데스크톱 브라우저와 그래픽 가속이 필요합니다.
브라우저에 WebGL 오류가 나오면 설정 > 시스템 > 그래픽 가속을 확인하세요.
회사/학교 PC에서 로컬 HTML 실행을 정책으로 차단하면 관리자에게 문의하거나,
Python이 설치된 PC에서 아래 로컬 서버 방법을 사용하세요.

[조작]
A / D : 좌우 조향
J : 가속; 후진 중에는 제동 후 전진
K : 제동; 거의 정지하면 자동 후진
L : 후륜 핸드브레이크
M : 효과음 음소거 / 해제 (상단 슬라이더로 음량 조절)
C : 체이스 > 와이드 > 범퍼 > 운전석
ESC : 일시정지 / 재개
R : 마지막 체크포인트 부근으로 복귀. 타이머가 시작된 뒤에는 5초 벌점.

[콘텐츠]
차량 5종, 랠리 스테이지 4개, 3랩 랠리크로스 1개.
타이어 4종, 날씨 4종. 선택값은 실제 브라우저 물리의 마찰에 반영됩니다.
완주 조건은 순방향으로 체크포인트를 순서대로 통과하는 것입니다.
최고 기록은 차량/코스/타이어/날씨별로 브라우저 localStorage에 저장합니다.
로컬 파일 저장이 차단된 브라우저에서는 기록이 유지되지 않을 수 있습니다.

[중요한 범위]
이 파일은 독립적인 JavaScript/WebGL 테스트 게임입니다.
Unity 프로젝트를 WebGL로 빌드한 결과가 아니며 Unity WheelCollider를 사용하지 않습니다.
브라우저 버전은 바퀴별 마찰력/조향력/토크를 적분하는 간소화된 차량 물리를 사용합니다.
Unity의 컴파일, 씬 생성, 차량 물리, Windows 실행 파일 검증을 대신하지 않습니다.
완성 게임이 아닌 플레이 테스트용 버전으로, 모델/환경/입자는 임시 제작입니다.
성능 60FPS는 보장하지 않으며, 정밀한 차체 충돌/서스펜션은 미구현입니다.
나무/바위/게이트 기둥은 간이 충돌 판정을 사용합니다.
전체 코스 완주/3랩 결과와 Chrome/Edge Windows 실기기 테스트는 아직 미검증입니다.

[테스트 결과]
TEST_REPORT.md를 참고하세요. Chromium에서 로컬 HTTP 서버로 테스트했습니다.
클라우드 관리 브라우저의 file:// 차단 정책 때문에 직접 파일 열기 테스트는 수행하지 못했습니다.
게임은 fetch, ES 모듈, 외부 CDN을 사용하지 않아 일반 로컬 파일 실행이 가능하도록 구성했습니다.

[선택: 로컬 서버 실행]
Python이 설치되어 있다면 이 폴더에서 터미널을 열고:
  py -3 -m http.server 8765 --bind 127.0.0.1
macOS/Linux에서는:
  python3 -m http.server 8765 --bind 127.0.0.1
Chrome/Edge 주소창에 http://127.0.0.1:8765 를 입력하세요.
종료는 서버 터미널에서 Ctrl+C입니다.

[효과음 v2]
처음 버튼을 클릭하면 브라우저 오디오가 활성화됩니다. 브라우저 탭 자체가 음소거되어
있으면 탭의 음소거도 해제하세요. BGM은 없습니다. 모든 효과음은 Web Audio 자체 합성입니다.
엔진/배기/터보/변속기 소리, RPM/차종별 음색, 기어 변속/후진, 4바퀴별 노면 구름음,
아스팔트 타이어 비명, 자갈/모래/진흙/눈 마찰음, 젖은 노면 물보라, 바람/비/눈,
핸드브레이크, 착지/충돌, 카운트다운/출발, 체크포인트/랩/완주, 메뉴/일시정지/복귀/카메라.
운전석에서는 외부 소리가 작아지며 공중에서는 지면 소리가 멈춥니다.

[주행 변경 v2]
A=좌측, D=우측 조향을 수정했습니다. 일반 자갈길 횡접지와 타이어 반응을 높이고
고속 조향각을 줄였습니다. L을 누르면 후륜 접지가 낮아져 의도적인 드리프트는 가능합니다.

[그래픽 변경 v2]
둥근 차체 메시/휠 아치, 고분할 휠과 림, 클리어코트 도장과 반투명 유리를 적용했습니다.
지형은 수만 개 정점으로 굴곡을 만들고 도로/잔디/바위에 디테일 셰이더를 적용했습니다.
구름 하늘, 산 능선, 720그루 수목과 4,500개 풀 군집을 프로시저럴 생성합니다.
원본보다 GPU 부하가 높아졌으므로 그래픽 가속을 켜고 성능이 부족하면 창 크기를 줄이세요.
실사 수준 에셋이나 외부 유료 에셋은 사용하지 않았습니다.
